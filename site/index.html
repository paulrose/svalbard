A cron job or scheduled CI workflow starts Svalbard. Svalbard opens a snapshot of a PostgreSQL or MySQL database and writes a backup from it. The snapshot closes. Only then does Svalbard upload the backup to storage, where it settles beside earlier backups.

Svalbard is an open-source database backup CLI, written in Rust. It is in development. The scene shows planned behaviour.

The name

Svalbard is an Arctic archipelago. Near Longyearbyen, the Svalbard Global Seed Vault keeps duplicate seed samples from gene banks around the world, so their collections can be rebuilt if the originals are lost. In 2015, the research centre ICARDA made the first withdrawal, to rebuild collections that the war in Syria had cut off. The project takes its name from the islands and the vault.
